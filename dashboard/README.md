# Dashboard

This folder contains a lightweight public dashboard for the Event Opportunity Radar project.

## Purpose

The dashboard is meant to provide a simple public preview of the project’s core concept:

- discover events
- rank them by fit and value
- highlight contribution-first opportunities
- surface local and virtual opportunities

## How to use

Open `index.html` in a browser to see the dashboard locally.

For a GitHub Pages deployment, publish this folder as the site root and keep the private personal workflow in a separate private configuration layer.

## Notes

- Keep public information in this dashboard.
- Keep personal notes, applications, and contact details in a private workflow outside the public repo.
- Use the public dashboard as a demo and contribution entry point.
- Keep the underlying logic in the main repository and the private dashboard data separate.
