# GitHub Project Guide

The GitHub repository page has two kinds of surfaces:

1. **Repository-controlled:** README, workflows, source tree, badges, screenshots, and documentation links.
2. **GitHub-controlled:** the About panel, Releases panel, deployment history, Packages panel, contributor graph, and language chart.

Use the links below as the project dashboard.

## About Panel

Open repository **Settings -> General -> About** and set:

- **Description:** `Evidence-aware event intelligence for finding verified dates, contribution paths, applications, contacts, and follow-through.`
- **Website:** `https://pavan755.github.io/event-opportunity-radar/`
- **Topics:** `event-discovery`, `opportunity-intelligence`, `volunteering`, `open-source`, `community`, `angular`, `google-apps-script`, `github-pages`

The README is the detailed About experience. It starts with the live app, then explains the product, usage, architecture, setup, contracts, automation, and contribution path.

## Releases

Releases are GitHub milestones, not runtime data updates. Create one when a meaningful product version is ready:

1. Open [Releases](https://github.com/Pavan755/event-opportunity-radar/releases).
2. Select **Draft a new release**.
3. Create a tag such as `v1.0.0`.
4. Use the release title `First public radar release`.
5. Link to the live app and summarize user-facing changes.
6. Publish the release.

Scheduled Event Agent Lite refreshes should remain ordinary commits, not releases.

## Deployments

Open [Deployments](https://github.com/Pavan755/event-opportunity-radar/deployments) to inspect the `github-pages` environment and open the latest published URL.

The deployment path is:

```text
Push to main
  -> GitHub Actions: Deploy static site to GitHub Pages
  -> npm ci --prefix ui
  -> Angular build with /event-opportunity-radar/ base path
  -> upload ui/dist/ui/browser
  -> deploy github-pages environment
```

The critical artifact directory is `ui/dist/ui/browser`. It contains the actual `index.html` generated by Angular.

## Actions

Open [Actions](https://github.com/Pavan755/event-opportunity-radar/actions) to:

- inspect quality-gate results
- run Event Agent Lite manually
- run the Pages deployment manually
- inspect build logs when a deployment is delayed or unavailable

The three active workflows are documented in [workflows.md](workflows.md).

## Packages

This repository does not publish a package. The Angular application is a static site, and the Apps Script modules are deployment source rather than a public npm package.

If a package is added later, document its purpose and installation command in the README before publishing it.

## Contributors

Open [Contributors](https://github.com/Pavan755/event-opportunity-radar/graphs/contributors) to see commit participation. Scheduled GitHub Actions commits are generated by `github-actions[bot]`; product, documentation, and source contributions remain attributable to their authors.

## Languages

GitHub's language chart is generated from tracked files. This repository is expected to show JavaScript/TypeScript and CSS/HTML because it contains:

- Angular UI source
- Apps Script JavaScript modules
- Node.js discovery tooling
- JSON configuration and Markdown documentation

Generated artifacts and documentation naturally affect GitHub's percentages; the chart is descriptive, not a build or quality metric.
